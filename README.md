# Skillora 🎓

Skillora is a full-stack e-learning platform where instructors can create and manage courses, and students can enroll, learn through structured content, take quizzes, and provider feedback through reviews.

---

## Tech Stack

- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Next.js API Routes / Server Actions
- **Database:** MongoDB (Mongoose)

---

## Features

### Instructor

- Create and manage courses
- Organize content into modules and lessons
- Publish courses
- Create quizzes

### Student

- Browse and manage courses
- Enroll in courses
- Access learning materials
- Take quizzes
- Leave reviews

---

## Architecture

- Role-based system (Instructor / Student)
- Modular course structure
- MongoDb-based data modeling

---

## Purpose

Skillora is a LMS platform to practise and demostrate full-stack development skills using Next.js and MongoDB.
